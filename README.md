## 🚀 Week 6 – Messaging, Notifications & Reviews System

### 📌 Project Overview

In Week 6 of my internship, I enhanced the **Skillora Freelancing Marketplace Platform** by implementing an interactive messaging system, a notification center, and a reviews and ratings system. These features improve communication between users, provide updates about important activities, and help build trust within the freelancing community.

### ✨ Key Features

**💬 1. Messaging and Chat System**
- Interactive conversation list with multiple conversations.
- Chat window displaying message history.
- Send messages through an input field.
- Search and select conversations.
- Unread message indicators.
- Local Storage integration to retain messages after refreshing the page.

**🔔 2. Notification Center**
- Centralized notification panel for important platform activities.
- Notifications for new messages, project updates, and reviews.
- Read and unread notification filters.
- Mark individual notifications as read.
- Mark all notifications as read.
- Local Storage integration to retain notification data.

**⭐ 3. Reviews and Ratings System**
- Submit reviews with a 1–5 star rating.
- Add reviewer names, project names, and written feedback.
- Display reviews with ratings and dates.
- Calculate and display the average rating.
- Show the total number of reviews.
- Store review data in Local Storage.

### 🛠️ Technologies Used

- **HTML5** – Page structure and content.
- **CSS3** – Responsive layouts and interface styling.
- **JavaScript** – Interactive functionality and event handling.
- **Local Storage** – Saving messages, notifications, and reviews in the browser.
- **Font Awesome** – Icons and interface elements, where used.

### 📱 User Interface

The Week 6 features are integrated into the existing Skillora project, allowing users to navigate between the homepage, messaging system, notification center, and reviews page without changing the overall project structure.

### 🎯 Learning Outcomes

- Implemented interactive chat functionality using JavaScript.
- Practiced storing and retrieving structured data with Local Storage.
- Developed notification filtering and read-status management.
- Created a star-based rating and review interface.
- Improved multi-page navigation and user experience.
- Strengthened frontend development skills using HTML, CSS, and vanilla JavaScript.

Week 6 focused on making Skillora more interactive by adding communication, notification, and reputation features to the existing freelancing marketplace platform.
